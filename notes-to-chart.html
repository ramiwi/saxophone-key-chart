Notes → key charts

Paste space-separated note rows (e.g. B4 C5). Notes are aligned into shared columns by their character position, so the same column lines up vertically across rows. Same diagrams as the key chart.

Type to search (or press Enter).

Select one source manually per search. The Session and Tunepal are live JSON endpoints. MuseScore and iReal Pro entries are informational because they don't provide a browser-friendly public note REST API. For those catalogs, use Custom REST tune API with your own backend/proxy endpoints: /search and /tunes/:id. Imported notes are transposed to your selected instrument (C/Bb/Eb) before rendering sax fingerings.

Notes use scientific pitch: letter, optional # or b, octave (e.g. A#4). Notes that start at the same character position align into the same column down the page — add or remove leading spaces to line things up. Commas are treated like spaces. Empty lines are skipped. A line starting with ; is a title for the next row (e.g. ; Song 1), shown next to its row number. With Diagrams per row set, each row uses that fixed number of equal-size columns and wraps any overflow onto new lines; clear it to align notes by character position instead.
